# Sonification V2 — Project Goals

## 1. Vision Statement
Transform the legacy 2015–2016 desktop Processing image-sonification sketch (`Tomasz Sulej & Bob Verkouteren`) into a modern, high-performance, real-time web application and mobile **"Sound Camera"**. 

Sonification V2 bridges visual databending and auditory synthesis: it treats digital image pixels and live video scanlines as continuous 1D audio waveforms, passes them through classic audio DSP plugin chains (biquad EQs, recursive delays, phasers, TB-303 acid filters, vinyl noise, analog tube saturation), renders the resulting glitched visuals at 60 FPS, and plays back the sonic waveform directly through device speakers.

---

## 2. Problem Statement
The original Processing sketch (`sonification.pde`):
- **Excessively Slow:** Processing a single $2000 \times 2000$ image takes 15–45 seconds due to sample-by-sample polymorphic Java method calls (`Piper.read()`), heap object autoboxing (`ArrayList<Float>` in reverb), and single-threaded execution.
- **Desktop & Java Bound:** Requires a local desktop environment with Java/Processing installed; cannot run online or on mobile devices.
- **Static Images Only:** Only supports static image files (`.jpg`, `.png`) processed in batch or single-frame mode; no live video or camera input.
- **No Direct Audio Playback:** Although it uses audio DSP math to glitch images, the user cannot actually hear the sound generated by their visuals.
- **No Cross-Device Workflow:** No way to design an effect chain on a desktop computer and instantly use it on a smartphone camera.

---

## 3. Desired End State
1. **Zero-Install Web App:** Runs in any modern web browser (Chrome, Safari, Firefox, Edge) on desktop, tablet, and mobile.
2. **Real-Time Performance:**
   - **Live Video / Mobile Camera Feed:** Runs at a stable **30–60 FPS** at responsive preview resolutions ($640 \times 360$ / $1280 \times 720$).
   - **High-Res Images:** Full 4K ($3840 \times 2160$) image processing in **$<80\text{ ms}$** via non-blocking Web Workers.
3. **The "Sound Camera" Experience:**
   - Real-time webcam and smartphone rear/front camera feed with audio sonification.
   - Live audio playback through headphones/speakers via Web Audio API. Pointing the camera at light, darkness, patterns, and movement dynamically modulates the soundscape.
   - Built-in video and audio recording (`MediaRecorder` $\to$ `.webm` / `.mp4`) and high-res snapshot capture.
4. **Desktop Studio $\leftrightarrow$ Mobile Camera Workflow:**
   - **Desktop View:** Deep modular audio rack with visual patch cords, detailed knob parameter controls, fine-tuned format settings, and wave analyzers.
   - **Preset Sharing:** User can click **"Send to Phone"** to generate an instant **QR Code** or compact URL link (`#preset=...`). Scanning the QR code opens the lightweight mobile viewfinder with the exact preset ready to record.

---

## 4. Key Success Metrics

| Metric | Target | Original Processing Baseline |
| :--- | :--- | :--- |
| **Preview Processing Latency** | $<10\text{ ms}$ per frame ($640 \times 360$) | $5,000\text{ ms} - 15,000\text{ ms}$ |
| **High-Res Image (4K) Time** | $<100\text{ ms}$ | $>40,000\text{ ms}$ (or Out of Memory) |
| **Live Camera Frame Rate** | 30–60 FPS uninterrupted | 0 FPS (Not supported) |
| **Platform Compatibility** | 100% web & mobile (iOS Safari & Android Chrome) | Desktop Java only |
| **Audio-Visual Latency** | $<20\text{ ms}$ buffer latency | No audio playback |
| **Preset Transfer Time** | $<2\text{ seconds}$ via QR code scan | None |

---

## 5. Scope & Guardrails
- **In Scope:**
  - 100% faithful mathematical port of the 22+ original DSP filters, streams, companding laws, and color space transforms.
  - Interactive modular filter rack (drag-and-drop ordering, enable/disable, parameter knobs).
  - Web camera (desktop) and mobile front/rear camera integration with facing-mode toggle.
  - Web Audio API real-time synthesis engine with volume control, mute, and waveform visualizer.
  - Video recording with synchronized audio and high-res photo capture.
  - QR-code based cross-device preset sharing and JSON import/export.
- **Out of Scope for Initial Launch:**
  - Cloud database user accounts (preset sync will be 100% client-side via QR codes and URL hashes to ensure privacy and zero server maintenance).
  - VST/AU DAW plugin export (can be considered for a future native build).
